## Existing Work And Execution Boundary

Apply the user's agreed testing scope and task authorization first. Do not delete pre-existing work, another agent's changes or uncommitted user files because a test was written late. The delete-and-restart examples below apply only to disposable code authored during an explicitly agreed TDD exercise; otherwise preserve the implementation and add a behavioral regression at the correct seam. Configuration, documentation and reversible low-impact changes do not require tests that merely mirror their implementation.
